L'essentiel en quatre points

1Le but du workflow

Ce workflow prépare automatiquement le COPIL d'un projet : Python enchaîne les étapes, CSAgent analyse les notes de réunion et rédige le rapport de synthèse.

Rien n'est diffusé sans l'accord du chef de projet.

2Le rôle de Python ⚡ Orchestration

Python orchestre le workflow : il enchaîne les étapes, lance les scripts, écrit les fichiers et choisit la suite selon le statut du projet.

Il calcule aussi les indicateurs (valeur acquise, indice de performance des coûts, retards, dérive) : ces chiffres viennent du code, pas d'une IA, donc ils sont exacts et reproductibles.

3Le rôle de CSAgent 🤖 Lecture et rédaction

CSAgent, l'agent IA, lit les notes de réunion écrites en texte libre. Il en tire les risques, les actions à mener et les décisions prises, puis rédige le rapport pour la direction.

Si le statut du projet est ROUGE, il prépare aussi une note d'escalade.

ExempleDans les notes, quelqu'un a écrit : « le prestataire n'a pas livré, on risque de décaler la mise en production ». CSAgent le repère et en fait un risque dans le rapport.

4Conclusion 👤 Décision humaine

Chaque outil fait ce qu'il fait le mieux : le code pour les chiffres, l'IA pour la lecture et la rédaction.

Le chef de projet garde la décision finale, et chaque étape reste tracée et vérifiable.
